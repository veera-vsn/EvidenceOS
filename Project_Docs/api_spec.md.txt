# API Specification
# EvidenceOS

**Purpose:**  
Define all backend endpoints, request/response shapes, and auth rules. This is your guide for generating the FastAPI backend.

---

## Base

- Base path: `/api`
- Auth:
  - API header: `Authorization: Bearer <token>`
  - Token from Supabase Auth or similar.
- Tenant context:
  - All requests include `workspace_id` in path or body.
  - Backend validates user has access to workspace.

---

## Auth

### 1. Sign Up

- Method: `POST`
- Path: `/auth/signup`
- Body:
  ```json
  {
    "email": "string",
    "password": "string",
    "organization_name": "string"
  }
  ```
- Response:
  ```json
  {
    "user_id": "string",
    "organization_id": "string",
    "workspace_id": "string"
  }
  ```

### 2. Login

- Method: `POST`
- Path: `/auth/login`
- Body:
  ```json
  {
    "email": "string",
    "password": "string"
  }
  ```
- Response:
  ```json
  {
    "token": "string",
    "user": {
      "id": "string",
      "email": "string"
    }
  }
  ```

### 3. List Users in Workspace

- Method: `GET`
- Path: `/auth/workspaces/{workspace_id}/users`
- Response:
  ```json
  [
    {
      "id": "string",
      "email": "string",
      "role": "string"
    }
  ]
  ```

## Documents

### 1. List Documents

- Method: `GET`
- Path: `/documents/workspaces/{workspace_id}`
- Query params:
  - `status` (optional): `pending|processed|failed`
- Response:
  ```json
  [
    {
      "id": "string",
      "name": "string",
      "type": "pdf|docx|xlsx|csv",
      "created_at": "datetime",
      "status": "string",
      "pipeline_run_id": "string|null"
    }
  ]
  ```

### 2. Upload Document

- Method: `POST`
- Path: `/documents/workspaces/{workspace_id}/upload`
- Body:
  - multipart form:
    - `file`: binary file.
- Response:
  ```json
  {
    "document_id": "string",
    "version_id": "string",
    "upload_status": "success"
  }
  ```

### 3. Get Document Detail

- Method: `GET`
- Path: `/documents/workspaces/{workspace_id}/documents/{document_id}`
- Response:
  ```json
  {
    "id": "string",
    "name": "string",
    "type": "string",
    "versions": [
      {
        "id": "string",
        "uploaded_by": "string",
        "created_at": "datetime",
        "status": "string"
      }
    ]
  }
  ```

### 4. Delete Document

- Method: `DELETE`
- Path: `/documents/workspaces/{workspace_id}/documents/{document_id}`
