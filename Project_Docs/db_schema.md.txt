# Database Schema Specification
# EvidenceOS

**Purpose:**  
Define concrete PostgreSQL tables, columns, types, constraints, indexes, and relationships for EvidenceOS. Use Supabase PostgreSQL.

---

## General Rules

- All tables have:
  - `id` UUID PRIMARY KEY DEFAULT gen_random_uuid().
  - `created_at` TIMESTAMPTZ NOT NULL DEFAULT NOW().
  - `updated_at` TIMESTAMPTZ NOT NULL DEFAULT NOW() (where applicable).
- Tenancy:
  - `organization_id` UUID NOT NULL on top-level tables.
  - `workspace_id` UUID NOT NULL on workspace-scoped tables.
- Use UUIDs for all IDs.
- Use JSONB for semi-structured payloads.
- Index foreign keys.
- Use row-level security policies in Supabase.

---

## Tables

### organizations

- `id` UUID PK.
- `name` TEXT NOT NULL.
- `created_at` TIMESTAMPTZ.
- `updated_at` TIMESTAMPTZ.

### users

- `id` UUID PK.
- `email` TEXT NOT NULL UNIQUE.
- `password_hash` TEXT (or use Supabase auth, skip if using external).
- `created_at` TIMESTAMPTZ.
- `updated_at` TIMESTAMPTZ.

### memberships

- `id` UUID PK.
- `organization_id` UUID NOT NULL REFERENCES organizations(id).
- `user_id` UUID NOT NULL REFERENCES users(id).
- `role` TEXT NOT NULL (e.g. admin, reviewer, auditor).
- UNIQUE (organization_id, user_id).

### workspaces

- `id` UUID PK.
- `organization_id` UUID NOT NULL REFERENCES organizations(id).
- `name` TEXT NOT NULL.
- `created_at` TIMESTAMPTZ.
- `updated_at` TIMESTAMPTZ.

### workspace_memberships

- `id` UUID PK.
- `workspace_id` UUID NOT NULL REFERENCES workspaces(id).
- `user_id` UUID NOT NULL REFERENCES users(id).
- `role` TEXT NOT NULL.
- UNIQUE (workspace_id, user_id).

### documents

- `id` UUID PK.
- `workspace_id` UUID NOT NULL REFERENCES workspaces(id).
- `name` TEXT NOT NULL.
- `type` TEXT NOT NULL (pdf, docx, xlsx, csv).
- `created_at` TIMESTAMPTZ.
- `updated_at` TIMESTAMPTZ.

### document_versions

- `id` UUID PK.
- `document_id` UUID NOT NULL REFERENCES documents(id).
- `version_number` INT NOT NULL.
- `storage_path` TEXT NOT NULL.
- `checksum` TEXT NOT NULL.
- `uploaded_by` UUID NOT NULL REFERENCES users(id).
- `upload_status` TEXT NOT NULL (uploaded, pending, failed).
- `created_at` TIMESTAMPTZ.
- UNIQUE (document_id, version_number).

### parsed_artifacts

- `id` UUID PK.
- `document_version_id` UUID NOT NULL REFERENCES document_versions(id).
- `artifact_type` TEXT NOT NULL (ocr, parsed_json, table).
- `storage_path` TEXT NOT NULL.
- `payload` JSONB.
- `created_at` TIMESTAMPTZ.

### evidence_fragments

- `id` UUID PK.
- `document_version_id` UUID NOT NULL REFERENCES document_versions(id).
- `fragment_type` TEXT NOT NULL (page, paragraph, row, cell).
- `reference` TEXT NOT NULL (e.g. "page 14", "row 28").
- `text_span` TEXT.
- `metadata` JSONB.
- `created_at` TIMESTAMPTZ.

### pipeline_runs

- `id` UUID PK.
- `workspace_id` UUID NOT NULL REFERENCES workspaces(id).
- `status` TEXT NOT NULL (queued, running, completed, failed).
- `started_at` TIMESTAMPTZ.
- `completed_at` TIMESTAMPTZ.
- `created_by` UUID REFERENCES users(id).
- `document_ids` UUID[] (or use child table).
- `created_at` TIMESTAMPTZ.

### pipeline_run_documents

- `id` UUID PK.
- `pipeline_run_id` UUID NOT NULL REFERENCES pipeline_runs(id).
- `document_id` UUID NOT NULL REFERENCES documents(id).
- `ocr_status` TEXT.
- `extraction_status` TEXT.
- `normalization_status` TEXT.
- `validation_status` TEXT.
- `recommendation_status` TEXT.
- `export_status` TEXT.
- `created_at` TIMESTAMPTZ.

### extracted_entities

- `id` UUID PK.
- `pipeline_run_id` UUID NOT NULL REFERENCES pipeline_runs(id).
- `entity_type` TEXT NOT NULL (vendor, contract, business_function).
- `metadata` JSONB.
- `extraction_version_id` UUID REFERENCES extraction_versions(id).
- `created_at` TIMESTAMPTZ.

### field_candidates

- `id` UUID PK.
- `extracted_entity_id` UUID NOT NULL REFERENCES extracted_entities(id).
- `field_name` TEXT NOT NULL.
- `value` TEXT.
- `value_json` JSONB.
- `confidence` FLOAT.
- `source_fragment_id` UUID REFERENCES evidence_fragments(id).
- `created_at` TIMESTAMPTZ.

### extraction_versions

- `id` UUID PK.
- `pipeline_run_id` UUID NOT NULL REFERENCES pipeline_runs(id).
- `model_version` TEXT.
- `prompt_config` JSONB.
- `created_at` TIMESTAMPTZ.

### vendors

- `id` UUID PK.
- `workspace_id` UUID NOT NULL REFERENCES workspaces(id).
- `canonical_name` TEXT NOT NULL.
- `metadata` JSONB.
- `created_at` TIMESTAMPTZ.
- `updated_at` TIMESTAMPTZ.

### vendor_aliases

- `id` UUID PK.
- `vendor_id` UUID NOT NULL REFERENCES vendors(id).
- `alias_name` TEXT NOT NULL.
- `source_document_version_id` UUID REFERENCES document_versions(id).
- `created_at` TIMESTAMPTZ.

### contracts

- `id` UUID PK.
- `workspace_id` UUID NOT NULL REFERENCES workspaces(id).
- `vendor_id` UUID NOT NULL REFERENCES vendors(id).
- `name` TEXT NOT NULL.
- `metadata` JSONB.
- `created_at` TIMESTAMPTZ.
- `updated_at` TIMESTAMPTZ.

### clause_candidates

- `id` UUID PK.
- `contract_id` UUID NOT NULL REFERENCES contracts(id).
- `clause_type` TEXT NOT NULL.
- `text_span` TEXT.
- `source_fragment_id` UUID REFERENCES evidence_fragments(id).
- `created_at` TIMESTAMPTZ.

### business_functions

- `id` UUID PK.
- `workspace_id` UUID NOT NULL REFERENCES workspaces(id).
- `name` TEXT NOT NULL.
- `metadata` JSONB.
- `created_at` TIMESTAMPTZ.

### business_function_links

- `id` UUID PK.
- `vendor_id` UUID REFERENCES vendors(id).
- `contract_id` UUID REFERENCES contracts(id).
- `business_function_id` UUID NOT NULL REFERENCES business_functions(id).
- `metadata` JSONB.
- `created_at` TIMESTAMPTZ.

### validation_results

- `id` UUID PK.
- `pipeline_run_id` UUID NOT NULL REFERENCES pipeline_runs(id).
- `rule_id` TEXT NOT NULL.
- `severity` TEXT NOT NULL (error, warning, pass).
- `target_entity_type` TEXT NOT NULL.
- `target_entity_id` UUID NOT NULL.
- `explanation` TEXT.
- `remediation` TEXT.
- `status` TEXT NOT NULL (pending, fixed, ignored).
- `evidence_ids` UUID[].
- `created_at` TIMESTAMPTZ.

### recommendations

- `id` UUID PK.
- `pipeline_run_id` UUID NOT NULL REFERENCES pipeline_runs(id).
- `recommendation_version_id` UUID REFERENCES recommendation_versions(id).
- `type` TEXT NOT NULL.
- `target_entity_type` TEXT.
- `target_entity_id` UUID.
- `confidence` FLOAT.
- `reason` TEXT NOT NULL.
- `status` TEXT NOT NULL (pending, approved, rejected, modified).
- `evidence_ids` UUID[].
- `created_at` TIMESTAMPTZ.

### recommendation_versions

- `id` UUID PK.
- `pipeline_run_id` UUID NOT NULL REFERENCES pipeline_runs(id).
- `model_version` TEXT.
- `prompt_config` JSONB.
- `created_at` TIMESTAMPTZ.

### review_actions

- `id` UUID PK.
- `workspace_id` UUID NOT NULL REFERENCES workspaces(id).
- `actor_id` UUID NOT NULL REFERENCES users(id).
- `action_type` TEXT NOT NULL (approve, reject, modify, ignore).
- `target_entity_type` TEXT NOT NULL.
- `target_entity_id` UUID NOT NULL.
- `previous_state` JSONB.
- `new_state` JSONB.
- `rationale` TEXT.
- `created_at` TIMESTAMPTZ.

### evidence_links

- `id` UUID PK.
- `target_entity_type` TEXT NOT NULL.
- `target_entity_id` UUID NOT NULL.
- `evidence_fragment_id` UUID NOT NULL REFERENCES evidence_fragments(id).
- `link_type` TEXT NOT NULL (source, support, reference).
- `created_at` TIMESTAMPTZ.

### exports

- `id` UUID PK.
- `workspace_id` UUID NOT NULL REFERENCES workspaces(id).
- `pipeline_run_id` UUID REFERENCES pipeline_runs(id).
- `name` TEXT NOT NULL.
- `status` TEXT NOT NULL (queued, generated, failed).
- `metadata` JSONB.
- `created_by` UUID REFERENCES users(id).
- `created_at` TIMESTAMPTZ.

### export_files

- `id` UUID PK.
- `export_id` UUID NOT NULL REFERENCES exports(id).
- `file_name` TEXT NOT NULL.
- `storage_path` TEXT NOT NULL.
- `file_type` TEXT NOT NULL (roi, validation_report, evidence_report, review_summary).
- `created_at` TIMESTAMPTZ.

### audit_events

- `id` UUID PK.
- `workspace_id` UUID NOT NULL REFERENCES workspaces(id).
- `actor_id` UUID REFERENCES users(id).
- `event_type` TEXT NOT NULL.
- `target_entity_type` TEXT.
- `target_entity_id` UUID.
- `details` JSONB.
- `created_at` TIMESTAMPTZ.

- `contracts_vendor_id_idx` ON contracts(vendor_id).
- `recommendations_pipeline_run_id_idx` ON recommendations(pipeline_run_id).
