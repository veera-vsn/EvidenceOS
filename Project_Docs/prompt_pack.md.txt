# EvidenceOS – Step-by-Step Build Prompts

**Purpose:**  
Use these prompts one by one with your AI code assistant. Each prompt builds one phase of the MVP.

Before each prompt:
- Load `project_runbook.md`, `evidenceos_prd_v2_...`, `evidenceos_sdd_v1.md`, `evidenceos_domain_model_v1.md`, and the relevant spec files.

## Phase 0: Project Scaffolding + Environment + Auth

**Prompt:**

```text

- Product: EvidenceOS (AI-powered DORA RoI evidence & validation copilot).

Goal:
- Implement Phase 0: project scaffolding, environment, and auth.

Constraints:
- Frontend: Next.js + TypeScript + Tailwind + shadcn/ui.
- Backend: FastAPI + Python.
- Database + Storage: Supabase (EU region).
- Use environment variables for all secrets.

Tasks:
1. Create project structure:
   - /frontend (Next.js).
   - /backend (FastAPI).
   - /workers.
   - /config.
2. Set up environment files and example .env.
3. Implement basic auth:
   - Signup endpoint.
   - Login endpoint.
   - Auth middleware.
   - Protected routes in frontend.
4. Implement basic organization and workspace creation flow.

Output:
- Generate all necessary files.
- Show file structure.
- Explain how to run locally.
```
